PowerGemPoS Updates

Download the newest version of the register program.

Get the Latest Version
  1. Sign in to GitHub if it asks (the download is private).
  2. Under Assets, download the Setup .exe file.
  3. On the register, open Settings → Data & Backups and make a backup first.
  4. Close PowerGemPoS, then run the downloaded Setup file.
  5. Open PowerGemPoS and check the version in Settings.
